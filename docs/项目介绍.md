# 集声

集声是一款面向 Windows 的本地语音整理工具。它能从视频或音频中识别对白，输出带时间轴的 SRT 字幕和 TXT 文本，也能把校对过的对白切成音频片段，生成适合 TTS 数据准备阶段使用的标注文件。

## 可以做什么

- **把视频变成字幕**。导入单个视频、音频或一批素材，提取音轨并生成字幕。可以在工作台预览字幕，自行选择输出目录。
- **按任务运行**。可以只抽取音频、只识别、只做人声分离或说话人分割，也可以运行完整流程。日语可用 anime-whisper，多语言可配合本地 Qwen3-ASR。
- **整理谁在说什么**。试听说话人片段，给声音分组命名并校对台词。对同一作品的后续素材，本地角色库可以提供匹配建议。
- **准备 TTS 标注**。把校对后的台词和切好的 WAV 一起导出。支持通用 TXT、GPT-SoVITS `.list`、Fish Speech 同名 `.lab`，以及 IndexTTS2 社区训练器 `.jsonl`。

## 适合谁

适合想为视频制作字幕、整理访谈或对白，以及需要把一批录音加工成 TTS 训练素材的人。第一次用时，可以从一段短视频开始，只运行识别并检查字幕。需要做 TTS 数据时，再启用说话人分割、核对角色和台词，最后选择目标模型的标注格式。

识别和数据整理在本机完成。下载模型或使用分享链接导入媒体需要网络。TTS 训练在对应的训练工具中进行。处理和分享素材时，请确认你拥有相应的使用权限。
