# GitHub 首次发布审查

从发布候选包解压到一个空目录，再建立新的 Git 仓库。确认暂存内容只包含该包中的源码、测试、文档及 GitHub 配置。Git 提交邮箱可使用账号设置里提供的 GitHub noreply 地址。

首次发布前，在私有仓库运行 Windows 测试工作流并检查结果。公开后检查 Secret scanning、Push protection、Dependabot 提醒和私密漏洞报告是否启用。只有管理员能修改对应的仓库设置。[敏感信息清理](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository) · [安全设置](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/managing-security-and-analysis-settings-for-your-repository) · [私密漏洞报告](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository)

发布候选包采用 MIT 源码许可。安装时下载的外部项目各自适用上游条款。发布包内置三张背景图，图片文件不含 EXIF、XMP 或其他附加元数据。为在线演示选择原创或获得授权的音视频素材，分享截图时检查路径、账号和媒体标题。将令牌、Cookie、导入媒体、模型、声纹库、日志和用户自行导入的背景图保存在发布目录之外。
